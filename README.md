# Explainable Phishing URL Detection & Threat Analysis System

## Overview

A machine learning system that detects whether a URL is
phishing or legitimate and provides explanations for its predictions.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- FastAPI
- Joblib
- Docker
- HTML/CSS/JavaScript
